# FOOTBALL AI 6.2

## 사용 방법

사이트를 열고 다음 세 가지만 하면 됩니다.

1. 축구 영상을 선택합니다.
2. 영상에서 26번 선수의 몸 가운데를 클릭합니다.
3. **분석 시작**을 누릅니다.

진행률은 자동으로 갱신되며, 완료되면 **결과 영상 다운로드** 버튼이 나타납니다. `/docs` 화면이나 작업번호를 직접 사용할 필요가 없습니다.

## Render 배포

이 폴더의 파일 네 개를 GitHub 저장소의 최상위 폴더에 올린 뒤, Render에서 `render.yaml`을 사용하는 Blueprint로 배포합니다.

`render.yaml`은 다음을 함께 설정합니다.

- 웹 서버 1개
- 무료 웹 서버
- 작업 상태를 관리하는 SQLite 저장소

현재 설정은 결제 정보 없이 배포할 수 있는 무료 플랜입니다. 무료 서버가 재시작되면 작업 상태와 결과 영상이 사라질 수 있으므로 분석 중에는 사이트를 닫지 마세요. 영구 보관이 필요해질 때 유료 디스크를 추가할 수 있습니다.

## 로컬 실행

Python 3.11 환경에서 의존성을 설치한 후 아래 명령으로 실행합니다.

```text
uvicorn app:app --host 0.0.0.0 --port 8000 --workers 1
```

브라우저에서 `http://localhost:8000`을 엽니다.
